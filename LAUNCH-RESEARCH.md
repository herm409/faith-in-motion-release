## Pattern brief (Faith in Motion)

### Must-have sections (ranked)

1. **Hero (asymmetric)** — Wordmark/nav · one-liner · subtitle · locked cover as object · single primary CTA · soft release/status line · ISBN as quiet chrome. *(Already strong on current site.)*
2. **Problem / invitation band** — Locked “Faith is not a standstill” opening; pastoral diagnosis of baptized freeze; who it’s for in one warm paragraph. *(Present.)*
3. **Inside the book** — 3–5 theme beats as numbered editorial list or staggered 7/5 splits — outcomes/themes, not chapter dump. *(Present as 01–04 list.)*
4. **Notify / Get-the-book strip** — One clear action; formats (paperback + ebook); ISBN; expectancy copy until Amazon live. *(Present; CTA is placeholder.)*
5. **About Herman** — Circular Colosseum headshot + fellow-traveler bio (husband, father, builder; fear wearing calling’s clothes). *(Present; keep short.)*
6. **Email / follow capture (upgrade)** — Soft “walk with the book” invite; optional free sample or discussion question; no growth-hack dark patterns.
7. **Trust / sincerity block (upgrade, careful)** — Prefer *who it’s for*, Scripture/theme honesty, early-reader letters when real — never invented pastor blurbs.
8. **Sticky mobile CTA bar** — Notify → Get the book when Amazon live. *(Present.)*
9. **Footer** — © Herman Davis · HD Media; privacy note once email exists.

*Defer (phase 2 / post-launch):* multi-retailer cloud, bonus ladder tiers, cohort/church kits, countdown clocks, logo walls.

### CTA pattern

| Phase | Primary CTA | Secondary | Email role | Do not |
|-------|-------------|-----------|------------|--------|
| **Until Amazon live** | **Notify me** (hero + buy strip + sticky) | Soft “Read a sample” / “One question to sit with” if asset exists | Capture for release day + one pastoral touch | Fake “Buy now,” countdown, “limited spots” |
| **Amazon live** | **Get the book** → Amazon (paperback/ebook) | Keep Notify→newsletter or “email when paperback ships” if needed | Optional: buy on Amazon → return → claim a free PDF reflection / Ch.1 | Force multi-retailer before one clean Amazon path works for KDP |
| **After first reviews** | Get the book | “Read a page” / discussion PDF | Status line only with *real* stars/count | Inflate numbers; invent “as seen in” |

**Receipt-claim pattern (from Clear / Contend / Angie / Zondervan):** when a free companion exists, Amazon remains the store; *this site* remains the relationship. Fit for FIM only if the companion is sincere (e.g. one discussion guide PDF), not a SaaS bonus stack.

### Proof / trust patterns that fit sincere Christian nonfiction

**Use**
- Locked one-liner + back-cover voice (already approved).
- “This book is for you if…” (stuck but sincere; baptized delay; gift in hand).
- Author as fellow traveler — lived seasons of fear-as-calling (from locked blurb), not celebrity pastor posture.
- Scripture-shaped specificity (Noah built / Abraham went / buried talent) as *substance*, not decoration.
- Real early-reader or pastor letters *when earned* — name + role, short quote; Sleep Again’s “letters, not blurbs.”
- Optional free sample chapter or single pastoral question (Contend Questions tease, scaled down).
- Post-launch: honest Amazon rating line only when true.

**Avoid**
- Fabricated endorsements, “bestseller” claims before they exist, fake media logos.
- Equal three-card “testimonial” grids with stock faces.
- Hype adjectives (explosive, life-changing guaranteed, you won’t believe).
- Author photo as hero (cover-locked: journey art leads; headshot only in About).

### Anti-patterns to avoid

| Anti-pattern | Why it clashes with FIM |
|--------------|-------------------------|
| Centered SaaS hero + 3 equal feature cards + logo cloud | Explicit DESIGN.md never; vibe-code mold |
| Purple→blue mesh, Inter/Geist/Poppins as identity | Breaks cream/navy + Playfair/Cormorant lock |
| Countdown timers, “only 47 left,” FOMO bars | Not pastoral; not quiet-premium |
| Tiered preorder carnival (1 / 3 / 10 copies + cohort upsell) | Fine for Contend’s stadium movement; wrong scale/tone for debut pastoral KDP |
| Glass-on-glass / stacked translucency | DESIGN.md never |
| Hype transformation headlines (“Crush fear in 7 days”) | Blurbs are invitation, not hustle |
| Front-cover author portrait | Cover lock: motion/gift, not author-as-subject |
| Fake proof / invented blurbs | Integrity > conversion tricks |

## Ranked upgrade list (for implementer)

Ready to apply to the existing editorial cream/navy single-page. Do **not** redesign from scratch.

### 1. Wire a real Notify capture (highest conversion gap)
**Now:** `#notify` anchors to a strip whose button loops to itself (COMP-NOTES: no mailto/form).  
**Do:** Replace with a quiet email form (name optional) + success state “We’ll email you when the Amazon link is live.” Store via simple form endpoint / Mailchimp / Resend later. Keep button label **Notify me**. Privacy one-liner in footer when live.

### 2. Add a soft “for you if” sincerity band (trust without fake blurbs)
Place after Problem or after Inside — short editorial checklist (3–5 lines), Sleep Again / Cognitive Sovereignty pattern:  
e.g. you love God and still feel stuck; you’ve baptized delay as “waiting”; you already sense a gift or open door; you want pastoral clarity, not hype.  
Typography: Cormorant body, Playfair kicker — **not** a card grid.

### 3. Dual-CTA when a sample exists (Clear / indie pattern, scaled)
Primary stays Notify (pre-Amazon). Secondary text link: **Read a sample** or **Sit with one question** — only if a real PDF/HTML excerpt or one discussion question is ready. Never a second loud button competing with Notify.

### 4. Status / formats line that matures cleanly
Hero + buy strip: keep “Paperback & ebook on Amazon — link coming soon.”  
When live: swap to **Get the book** + format chips (Paperback · Ebook) + ISBN unchanged. Optional quiet date if a firm release day is set (Contend-style chrome, not a timer).

### 5. Strengthen buy strip as the “chapter break” CTA
Make `#notify` / buy band feel like a full-bleed editorial close (navy or cream slab with breathing room), not a thin SaaS banner. One headline from locked voice (“When God gives a gift or a vision, He invites you to step.”) + form + formats. Sticky bar label flips Notify → Get the book in lockstep.

### 6. Optional TOC / “a page from inside” peek
One short excerpt pull-quote or 4–6 chapter titles in a single column (War on Reality / Cognitive Sovereignty) — substance proof for readers who don’t know Herman yet. Keep sparse; no accordion carnival.

### 7. About band: one credential of proximity
Keep circular headshot. Add one concrete line of place/life if Herman approves (builder/entrepreneur season; Colosseum portrait context is visual only). Avoid long CV. Match locked blurb: “theology that walks.”

### 8. Post-launch proof slot (empty until real)
Reserve a slim band for 1–3 early-reader letters or “★★★★★ · *n* ratings on Amazon” — hidden or commented until data exists. Pattern: Sleep Again letters; never placeholder Latin or invented pastors.
